# Font licenses

Orbsona includes local copies of the following open source variable fonts:

- Geist and Geist Mono, distributed by Vercel under the SIL Open Font License 1.1.
- Jost, designed by Owen Earl and distributed under the SIL Open Font License 1.1.

The font files are stored in `src/app/fonts` and loaded with `next/font/local`.
